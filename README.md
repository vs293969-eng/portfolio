# Vaishnavi Singh – Portfolio

Plain HTML, CSS and JavaScript. No build step.

## Files you add or replace
- `assets/images/profile.jpg` – your photo (already added)
- `assets/documents/resume.pdf` – your resume (already added)
- `assets/images/project-1.jpg` – screenshot of AI Doubt Solver (not added yet; a colour block shows until you add it)

File names must be lowercase and exact.

## Edit content
Open `index.html`. Every section starts with a comment saying what to edit.
- **Add a project:** copy one `<article class="card project">` block and change the text.
- **Add a certificate:** copy one `<article class="card">` block in the Certifications section.
- **Project contribution and link:** follow the `TODO` comments in the Projects section. For the link, put your URL in `href` and delete the word `hidden`.
- **Colours:** change the variables at the top of `css/style.css`.

## Publish on GitHub Pages
1. Create a new public repository on GitHub. Name it `vs293969-eng.github.io` for the short address `https://vs293969-eng.github.io`.
2. Upload everything inside the `portfolio` folder (so `index.html` is at the top level).
3. Go to Settings, then Pages.
4. Under Source choose Deploy from a branch, select `main` and `/ (root)`, then Save.
5. Wait one or two minutes and open the live link shown on that page.

## Test before sharing
- Resume button downloads the PDF
- Email, phone, LinkedIn, GitHub and Verify Certificate links open correctly
- Theme toggle and mobile menu work on your phone
